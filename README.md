# 📊 CodeAlpha Task 3 — Data Visualization

## Superstore Sales Data Visualization and Business Insights

This project was completed as part of the **CodeAlpha Data Analytics Internship – Task 3: Data Visualization**.

The project transforms Superstore sales data into meaningful visualizations and uses them to identify patterns in sales, profit, products, categories, and regions.

## 🎯 Objective

The main objectives of this project are:

- Analyze sales trends over time
- Compare sales across different categories
- Analyze profit performance
- Compare regional sales
- Identify top-performing products
- Study the relationship between discount and profit
- Analyze sales by sub-category
- Examine correlations between numerical variables

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📊 Dataset

The project uses the **Superstore Sales Dataset** containing information about:

- Order Date
- Ship Mode
- Customer
- Segment
- Region
- Category
- Sub-Category
- Product
- Sales
- Quantity
- Discount
- Profit

## 📈 Visualizations

The notebook contains the following visualizations:

1. Monthly Sales Trend
2. Total Sales by Category
3. Total Profit by Category
4. Total Sales by Region
5. Top 10 Products by Sales
6. Discount vs Profit
7. Sales by Sub-Category
8. Correlation Heatmap

## 🔍 Analysis

The visualizations are used to understand:

- How sales change over time
- Which categories contribute to sales and profit
- Differences in sales across regions
- Products generating high sales
- Performance of individual sub-categories
- The relationship between discounts and profitability
- Relationships among sales, quantity, discount, and profit

## 📌 Key Insights

The analysis provides a visual overview of business performance and helps identify important patterns in the Superstore dataset.

The combination of time-series charts, categorical comparisons, scatter plots, bar charts, and correlation analysis provides multiple perspectives for understanding the data.
